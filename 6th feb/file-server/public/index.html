File Server - Plain HTML Only

This is a simple HTML page without any CSS styling.

Features:

  • Only serves index.html on root path (/)
  • No CSS files are served (styles.css will show 404 error)
  • All other requests return 404 Not Found
  • 500 error can occur if there's a server issue

Test It:

  • Root: http://localhost:3004/ ✅ Works
  • CSS: http://localhost:3004/styles.css ❌ 404 Error
  • Any other path: http://localhost:3004/anything ❌ 404 Error

Open browser console to see requests for missing files!
