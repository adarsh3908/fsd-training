📁 File Server with CSS Support

This server serves HTML, CSS, JS, and other static files without errors.

Features:

  • ✅ Serves index.html on root path (/)
  • ✅ CSS files are served properly (styles.css)
  • ✅ Supports multiple file types (HTML, CSS, JS, JSON, Images)
  • ✅ Returns 404 for files that don't exist
  • ✅ Returns 500 on internal server errors

Test Links:

  • 🏠 Home (index.html)
  • 🎨 Styles (styles.css)
  • ❌ Non-existent file (404 error)

Difference from file-server:

file-server: Only serves HTML, CSS returns 404 error

file-server-with-css: Serves HTML + CSS without errors ✅
